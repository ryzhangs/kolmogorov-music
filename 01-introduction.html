Introduction to Kolmogorov complexity

Opens with two binary strings of the same length, one patterned ($0101\ldots01$) and one random-looking, alongside two short melodies: a repeated scale and an unpredictable line. Asks which is simpler to describe. Gives the formal definition $K_U(x) = \min\{|p| : U(p) = x\}$ for a fixed universal Turing machine $U$. Covers the bounds $K(x) \le |x| + c$ and $K(0^n) \le \log n + c$, and shows how structure in a string turns into a short program.

Which is simpler?

Intuitively we know that $11111$ is simpler (can be represented as $1^5$) to encode than a random string of bits such as $10010$. What we will explore later on is how this can be translated in terms of music. Music like most things can be encoded as information with bits/numbers. A complex jazz fusion arrangement will have constantly changing chords and unpredicatable jazz solos, while a song heard on the radio repeats a catchy melody many times, which one could intuitively believe to be more compressible.

Formal definition

We denote the Kolmogorov complexity as: $$K_U(x) = \min\{|p| : U(p) = x \text{ for a fixed universal TM } U\}$$ One can reason that this defines the minimum length input any TM takes to output $x$ where the input represents in a sense, the compressed representation of $x$.

Recall an important property of Turing Machines is that they are encodable and thus countable. As such, we can enumerate all TMs: $$\langle M_1, M_2, M_3, ...\rangle$$

Thus we can define the universal TM $U$: $$U(0^n1) = M_n() = x$$ Essentially, $n$ is the $n$th TM in our enumeration, so the input to $U$ informs it what $M_n$ is, and $U$ simulates $M_n$ on the empty string $\epsilon$.
